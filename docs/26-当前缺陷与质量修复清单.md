## B-008 Meta-Agent 对话式创建显示内部聚合 prompt

- 状态：已修复
- 建议 scope：`meta`, `workbench`
- 问题：对话式创建确认后，系统把内部聚合的 `Create a Moyu Agent from this conversation...` prompt 作为新的 user message 写入 WorkStore，用户会在 Workbench 中看到自己没有说过的话。
- 根因：`createAgentWithMeta` 默认会通过 `recordRunConversation` 写入本次 run 的 `prompt`，对话式创建复用该函数时没有区分“真实用户消息”和“内部聚合 prompt”。
- 修复：
  - `createAgentWithMeta` 新增 `recordPromptMessage` 选项，默认保持 CLI / 单次创建行为。
  - Meta-Agent 对话式创建确认时传入 `recordPromptMessage: false`，保留 plan / summary，但不展示内部聚合 prompt。
- 验收标准：
  - 对话式创建确认后，WorkStore 中只保留用户真实输入、checkpoint、plan 和 summary。
  - `trace.run.input.prompt` 仍保留完整聚合需求，便于追溯。
- 测试 / 验证：
  - `node --import tsx --test src/meta/conversation.test.ts src/meta/create-agent.test.ts`：通过，3 tests
  - `npm run typecheck`：通过
  - HTTP 验收：`POST /api/meta/conversation` 第一轮返回 `ready_to_create`，第二轮“确认创建”返回 `created`、`validation: true`，消息流不包含内部聚合 prompt。
- 闭环 commit：`fix(meta): 隐藏对话式创建内部 prompt`
