# v0.1-alpha 验收记录

> 目标：记录 v0.1-alpha Workbench 闭环的验证结果、已知限制和后续修正项。

## 1. 当前验证结果

已通过自动化验证：

- `npm test`
- `npm run typecheck`
- `npm run build`

已通过本地服务验证：

- `GET /api/health`
- `GET /api/workbench`
- `GET /api/agents`
- `GET /api/runs/:id`
- `GET /api/artifacts/:id`
- `GET /api/artifact-content?id=<artifact_id>`
- `POST /api/meta/create-agent`
- `POST /api/meta/install-agent`
- `POST /api/agent/run`

已通过功能路径验证：

- Meta-Agent 可以生成 Agent 草案。
- Agent 草案可以安装到 `agents/`。
- Workbench Agents 列表来自真实 `agents/` 目录。
- 已安装 Agent 可以 dry-run 运行。
- Workbench Work 列表可以按 Run 切换右侧 Trace / Artifact 上下文。
- dry-run 无产物时展示空态，并提示查看 Trace。
- `file://` 静态打开时会提示“静态预览模式”，并引导打开本地服务地址。
- AgentDraft 会记录为 `agent-draft.json`，并在安装成功后标记为 `installed`。
- 安装冲突会返回冲突 Agent、源路径、目标路径和建议动作，并将未安装草案标记为 `install_conflict`。

## 2. 浏览器验收状态

本地服务地址：

```text
http://127.0.0.1:4177/ui/workbench-prototype/
```

2026-06-07 浏览器验收进展：

- 页面可通过本地服务地址打开，并显示“本地引擎运行中”。
- 选中已安装 Agent 的 dry-run 时，运行按钮可用，安装按钮禁用。
- 选中 `meta/create-agent` 草案 Run 后，右侧产物列表刷新为真实草案文件，安装按钮恢复可用。
- 本轮已补充安装 / 运行操作区的默认状态提示，避免禁用按钮没有原因说明。

人工点击验收仍需覆盖：

- 点击“确认创建”后，右侧产物树刷新为真实草案文件。
- 点击文本产物后，文件内容预览正常加载。
- 点击“安装 Agent”后，左侧 Agents 列表出现新 Agent。
- dry-run 运行后，左侧 Work 列表新增 prompt 标题的任务。
- 点击不同 Work 后，右侧 Trace / Artifact 上下文同步切换。
- `file://` 打开时显示静态预览提示；`http://127.0.0.1:4177` 打开时显示本地引擎运行中。

## 3. 已知限制

- 当前 Workbench 仍是静态原型文件，不是正式前端工程。
- Work / Message 尚未进入独立持久化表；AgentDraft 当前以 `agent-draft.json` 最小记录表达。
- 安装冲突已提供结构化提示，尚未提供版本更新或差异合并 UI。
- 为避免浏览器验收生成额外正式 Agent，本轮未在 UI 中点击会新建 `agents/custom__image-prototype-v3` 的安装动作。
- 真实图片生成依赖本地 `.env` 中的 OpenAI-compatible 图片中转配置。

## 4. 下一步

1. 完成一次可见浏览器人工点击验收。
2. 修正验收中发现的 UI 状态、文案和布局问题。
3. 将 AgentDraft JSON 记录演进为可查询、可版本化的数据层。
4. 为安装冲突增加更明确的版本化处理路径。
