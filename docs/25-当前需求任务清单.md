# 25 - 当前需求任务清单

## F-001 设置中心落地为真实前端模块

- 状态：进行中（当前为 Workbench 原型态）
- 建议 scope：`workbench`
- 目标：把设置中心从静态原型迁移为正式前端模块，具备真实路由、状态管理和 API 数据接入
- 验收标准：
  - Models / Knowledge / Skills / Tools / MCP / Runtime 六个分组可切换
  - 数据来自真实 API，不依赖页面硬编码
  - 设置页具备空态、加载态、失败态
- 测试 / 验证：
  - 前端渲染测试
  - 本地点击验收
- 闭环 commit：
