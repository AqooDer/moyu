# 14 - UI 原型与信息架构

> 设计文档前 13 篇定义了**有什么模块、跑什么流程**,本文回答**用户看到什么、点什么、按什么顺序**。
>
> 阶段定位:**思考型原型**(Markdown + ASCII 线框),不是给设计师交付的视觉稿。目标是让单人开发者在写 v0.1 之前先把"用户能看到的东西"摸具体,避免到代码阶段才发现交互断点。
>
> 撰写日期:2026-05-20

## 1. 设计原则(UI 层面的几条铁律)

1. **本地优先要有体感**:不只是技术承诺,UI 必须有可见信号——"全部数据在你电脑里"出现在 Onboarding 和设置首页。
2. **Trace / Artifact 一等公民**:任何 Run 一定能两键点开 Trace 和产出;不要藏在"高级"里。
3. **对话 + 表单双通道**:Meta-Agent 不只是聊天框;关键槽位必须用卡片式表单暴露,降低对话来回成本(`05 §4.2`)。
4. **Onboarding 不能丢人**:首启动 5 步内必须能跑出第一个 Run;每一步失败必须有明确分类原因,严禁笼统"调用失败"(`09 §1.5`)。
5. **可中断 / 可暂停 / 可观察**:长任务必须有可见进度 + 暂停 + 取消按钮;不允许"已开始就不能停"。
6. **危险操作二次确认**:删除 Task / 删除 Agent / 大规模规则变更 / Workspace 重置——全部二次确认 + 影响范围说明。
7. **不假装智能**:Coverage 60% 就显示 60%,不要四舍五入到 80%;失败就说失败,不要给"已完成"的假象。

## 4. 关键用户流程(序列图风格)

### F-01 首次安装 → 跑出第一组原型图(end-to-end happy path,v0.1 首发场景)

```
   │  核心:配置 openai-compat provider(中转站 base_url + key)
   │  并完成 1 次最小测试调用(0.5s,< $0.01)
   ▼

   │  用户说"我要画原型图"
   │  Meta-Agent 推荐 `image-gen/prototype-v1` Recipe
   │  v0.1 走 RECIPE_PICK + 内置 Skill 装配(不现造)
   ▼

   │

```

**断点检查清单**(任一处断,流程就跪):
- [ ] Step 2 Key 输入有粘贴空格 → 必须 trim 后再校验
- [ ] Step 3 测试调用 > 30s 无响应 → 必须超时提示(中转站延迟敏感)
- [ ] Step 4 用户跳过 Recipe → 不能让首页空白,必须显示"开始你的第一个 Task"引导
- [ ] S-04 提交后无任何反馈超过 5s → 必须显示"正在准备 Run…"
- [ ] S-06 长时间无图返回 → 必须显示心跳"等待生图模型响应…"
- [ ] 单张图 b64 解码或落盘失败 → 该格子标红但不阻塞其他 3 张
- [ ] 中转站 5xx → 错误卡片明确区分"网络问题 / 余额不足 / 模型不存在",不能给"调用失败"四个字

## 6. 关键状态与微交互

### 6.1 Run 生命周期在 UI 的呈现

| 后台状态(`06 §2`) | UI 徽章 | 视觉 | 可操作 |
| --- | --- | --- | --- |
| `queued` | ⏳ 排队中 | 灰 | 取消 |
| `preparing` | 🟡 准备中 | 黄, 旋转 | 取消 |
| `running` | 🟢 ▶ Running | 绿,Step 实时 | 暂停 / 取消 |
| `paused` | ⏸ 已暂停 | 蓝 | 继续 / 取消 |
| `cancelling` | 🟠 取消中 | 橙,禁所有操作 | (不可点) |
| `succeeded` | ✅ 成功 | 绿勾 | 重跑 / 导出 |
| `succeeded`(coverage<80%) | ⚠ 成功(质量低) | 黄,加 ⚠ | 重跑 / 编辑 |
| `failed` | ❌ 失败 | 红 + 错误原因 | 重跑 / 查 Trace |
| `cancelled` | ⊘ 已取消 | 灰 | 重新启动 |

### 6.2 LLM 流式输出
- Step 详情 drawer 默认展开"输出",字符级 append
- 流式期间禁用"复制"按钮(防部分复制)
- 中断后保留已输出片段,标 `[stream interrupted]`

### 6.3 长任务进度
- Run 整体进度 = 已完成 Step / 总 Step,但**不预测时间**(LLM 时长方差大,假预测比无预测更伤信任)
- 显示已耗时,不显示预计剩余
- 章节 fanout 并行,进度条显示"已完成 4/12"

### 6.4 危险操作二次确认

| 操作 | 文案 |
| --- | --- |
| 删除 Task | "将删除 N 个 Run 与 M 个 Artifact 版本,不可恢复。确认?" |
| 删除 Agent | "该 Agent 有 K 个 Task 引用,删除后这些 Task 将无法重跑。确认?" |
| 重置 Workspace | "将清除全部 Agent / Task / Run / Trace,**不可恢复**。请输入 Workspace 名以确认:[___]" |
| 大规模规则变更 | "将影响近 7 天 X% 的 Run。建议先 A/B 试跑一周。仍要直接生效?" |
| 撤销 Monitor 建议 | (低风险, toast 提示即可) |

### 6.5 主题
- 默认跟随系统(macOS 亮 / 暗)
- 设置可强制
- 暗色模式必须测试 Artifact 预览(尤其 docx 黑底白字)
